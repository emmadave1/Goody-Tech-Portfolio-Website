# Goody Tech Portfolio Website

A modern and responsive portfolio website built to showcase the creative work, services, and brand identity of a graphics and brand designer. The website highlights featured projects, services, and contact information in a visually engaging and user-friendly experience.

## Features

* Modern and responsive design
* Smooth animations and transitions
* Portfolio showcase
* Services section
* About section
* Contact section
* SEO-friendly structure
* Fast and optimized performance

## Tech Stack

* React
* TypeScript
* TanStack Start
* Tailwind CSS
* Vite
